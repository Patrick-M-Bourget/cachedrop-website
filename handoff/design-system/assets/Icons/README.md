# Icons

CacheDrop's stroke icon set: 24×24 viewBox, 1.8 stroke, round caps and joins, single ink `#1D1D1F` (`ink`, light theme). An `<img>` cannot recolour them; in React use `CacheDrop.Icon` with the same names, which draws in `currentColor`.

- `download.svg`: download buttons only.
- `arrow-right.svg`: trailing arrow on ArrowLinks.
- `chevron-right.svg`: breadcrumb separators, “Review files ›”.
- `terminal.svg`: developers, developer caches.
- `film.svg`: creators, video caches.
- `drive.svg`: disk, storage overview, system caches.
- `sparkle.svg`: Smart clean.
- `list.svg`: Cleanup plan.
- `trend.svg`: Storage trends.
- `clock.svg`: History.
- `folder.svg`: Locations & access.
- `laptop.svg`: This Mac.
- `box.svg`: Downloads to review.
- `close.svg`: dismiss a dialog.
- `check.svg`: success, copied, done.
- `copy.svg`: copy to clipboard.
- `message.svg`: feedback.
- `trash.svg`: moves to the Trash.
- `shield.svg`: safety principles.
