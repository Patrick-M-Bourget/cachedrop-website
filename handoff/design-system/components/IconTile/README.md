# IconTile

A rounded square holding one icon: the visual anchor of a feature card or app category.

**Provide** `icon`; `size` `md` 44px (feature cards, default), `lg` 56px (utility-page hero), `sm` 36px (app rows); `tone` `dev` or `downloads` only for app categories.

- Neutral tiles (`surface-subtle` + `ink`) on the website; tinted tones only inside the product mock.
