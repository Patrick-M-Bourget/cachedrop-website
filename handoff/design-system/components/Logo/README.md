# Logo

The CacheDrop lockup: the brand mark (a drop with a check cut out of it, the app's `BrandMark`) and the name set in `title-sm` (15px, 600), with an optional BETA `Tag`.

**Provide** `href` to make it the home link (adds `aria-label="CacheDrop home"`), `beta` while in public beta, `markOnly` for tight spaces, `size` for the mark's height in px (width follows its 372:510 proportion).

- Colour is `ink` (it inherits `currentColor`); never recolour it to the accent. The check is a cut-out, so the ground shows through it.
- 18px-tall mark in the nav, 16px in the footer; 8px gap to the name. The app uses 24pt with a 17pt medium name.
- Never use the full-colour app icon in its place.
