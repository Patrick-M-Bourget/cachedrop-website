# StatusPill

A rounded pill that states a fact or status in one short line: the hero's beta line, or a state in the app.

**Provide** `children`; optional `tone` (`neutral` default, `accent`, `success`, `danger`) and `dot` (`true` = success green, or a tone name).

- The neutral pill with a green dot sits above the homepage H1 and carries a keyword (“Free Mac storage cleaner · Public beta”).
- Status meaning is always in the words; the dot is decoration. Never a dot alone.
- One pill per hero. Keep it under ~48 characters.
