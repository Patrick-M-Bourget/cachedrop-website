# Icon

The CacheDrop line-icon set: 24px grid, round caps and joins, 1.8 stroke at 14–18px (1.6 from 20px up), drawn in `currentColor`.

**Provide** `name` (an `IconName`) and optional `size` (px). Pass `label` only when the icon carries meaning on its own; otherwise it is `aria-hidden`.

Names: `download`, `arrow-right`, `chevron-right`, `terminal` (developers), `film` (creators), `drive` (disk / overview), `sparkle` (smart clean), `list` (cleanup plan), `trend` (storage trends), `clock` (history), `folder` (locations), `laptop` (this Mac), `box` (downloads), `close`, `check`, `copy`, `message` (feedback), `trash`, `shield` (safety).

- Sizes: `icon-xs` 12 (breadcrumbs), `icon-sm` 14 (arrow links), `icon-md` 18 (buttons), `icon-lg` 22 (feature tiles).
- Never use emoji as icons. The emoji rating scale in feedback is content, not iconography.
- Outside React, use the matching SVG files in the Icons asset group (ink `#1D1D1F`).
