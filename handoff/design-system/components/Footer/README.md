# Footer

Four columns: brand blurb, Cleaning Guides, Product, Platform; then the legal line.

**Provide** nothing for the standard footer; `columns`, `blurb`, `legal`, `status` to override.

- The Cleaning Guides column must keep its exact-match anchors (“Clear Developer Caches”, “Clear Adobe Media Cache”): they pass link authority to the guides.
- Legal line names every trademark the page mentions (Apple, Xcode, Adobe, Final Cut Pro).
