# InlineCode

A path, command or flag inside running text, in JetBrains Mono at 0.86em on a `surface-subtle` chip with a `line` border.

**Provide** the literal text. Use it for anything a reader could type: paths, commands (`npm install`), flags (`--volumes`), file extensions.

- Keep it short; anything longer than ~60 characters or meant to be copied goes in a `CodeBlock`.
