# RatingScale

The five-step satisfaction scale from the feedback brief: 😡 😕 😐 🙂 😍, as toggle buttons with a selected ring.

**Provide** `value` + `onChange` (controlled) or `defaultValue`. Values: `angry`, `meh`, `neutral`, `happy`, `love`.

- Each button has a spoken label (“Very unhappy” … “Love it”) and `aria-pressed`.
- Only in the feedback form. Emoji appear nowhere else in the product.
