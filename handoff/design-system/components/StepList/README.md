# StepList

A numbered list with mono 01/02/03 markers: hairline `rows` for principles beside a heading, or `cards` for install steps.

**Provide** `items` `[{ title, body }]`, `variant` (`rows` default, `cards`), `start`.

- Numbers only when order is real (a process, or principles read in sequence). For unordered features use `FeatureCard`.
- 3 items is the norm; never more than 5.
- Titles are short claims (“You review first”); bodies one or two sentences.
