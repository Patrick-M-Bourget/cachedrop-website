# ReviewRow

One cleanup category in the app’s “Recommended for review” list: tinted icon tile, title, one-line explanation, size and a Review files action.

**Provide** `title`, `detail`, `size` (human-readable, “About 3.7 GB”), `icon`, `tone` (`dev` / `downloads`), `onReview`.

- The detail line says why it is safe (“that tools rebuild”), not just what it is.
- Sizes are estimates; prefix with “About” unless measured exactly.
