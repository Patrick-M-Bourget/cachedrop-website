# Chip

A monospace label for a real path, folder or file type: what a card targets.

**Provide** text exactly as the user would see it on disk: `node_modules`, `~/Library/Logs`, `.cfa / .pek`. Wrap several in a `.cd-chips` row (6px gap).

- Only for literal technical names. Never for marketing tags or categories.
- 3 chips per feature card, separated from the body by a `line` rule.
