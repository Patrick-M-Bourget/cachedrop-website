# FAQList

Questions and answers, always visible (no accordions), separated by hairlines. Built to be quoted by search and answer engines.

**Provide** `items` `[{ q, a }]`; `variant="article"` on guide pages (16px answers in `ink-body`); default on the homepage (15px in `ink-soft`).

- Each question is phrased the way people search it (“How do I free up space on my Mac?”).
- The first sentence of each answer answers it outright (“Yes.” / “No.” / a definition), then gives one supporting detail.
- 5–6 questions per page; mirror them exactly in FAQPage structured data.
